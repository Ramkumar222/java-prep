01What is Java? Features of JavaFAQ▼

Explanation

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible. It was developed by James Gosling at Sun Microsystems (now Oracle) and released in 1995.

Key Features

  • Platform Independent — "Write Once, Run Anywhere" (WORA). Java code compiles to bytecode that runs on any JVM.
  • Object-Oriented — Everything is an object (except primitives). Supports Encapsulation, Inheritance, Polymorphism, Abstraction.
  • Robust — Strong memory management, no pointers, garbage collection, exception handling.
  • Secure — No explicit pointer access, bytecode verifier, SecurityManager, class loading mechanism.
  • Multithreaded — Built-in support for concurrent programming.
  • Architecture-Neutral — Bytecode is not dependent on any processor architecture.
  • Distributed — Supports RMI, EJB, web services for distributed computing.
  • Dynamic — Supports dynamic loading of classes at runtime via reflection.

Often the first question asked. Cover at least 5 features with brief explanations.

ClassLoader Subsystem

  • Bootstrap ClassLoader — Loads core Java classes from rt.jar (written in C/C++)
  • Extension/Platform ClassLoader — Loads from ext directory
  • Application ClassLoader — Loads from classpath (your classes)

JIT Compiler

The Just-In-Time (JIT) compiler converts frequently executed bytecode ("hot spots") into native machine code at runtime for better performance. Without JIT, the interpreter translates bytecode line-by-line which is slower.

04main() Method — Why public static void main(String[] args)?Tricky▼

Breakdown

  • public — JVM must access it from anywhere (outside the class)
  • static — JVM calls it without creating an object of the class
  • void — It doesn't return anything to the JVM
  • main — The name JVM looks for as the entry point
  • String[] args — Command-line arguments passed as an array of Strings
Java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
⚠️ Common Question

Can we overload main()? Yes! But JVM always calls public static void main(String[] args). Other overloaded versions are treated as normal methods.

07Type Casting — Widening & Narrowing▼

Widening (Implicit) — Automatic

Smaller type → Larger type. No data loss. Done automatically by compiler.

byte → short → int → long → float → double

Narrowing (Explicit) — Manual cast required

Larger type → Smaller type. Possible data loss. Requires explicit cast.

Java
// Widening (implicit)
int i = 100;
long l = i;       // int → long automatically
double d = l;     // long → double automatically

// Narrowing (explicit)
double price = 99.99;
int rounded = (int) price;  // 99 (decimal truncated)
byte b = (byte) 130;       // -126 (overflow!)

01Classes and ObjectsFAQ▼

Explanation

A Class is a blueprint/template that defines the structure (fields) and behavior (methods). An Object is an instance of a class — a real entity created in memory.

Java
// Class = Blueprint
public class Car {
    String brand;
    int speed;

    void accelerate() {
        speed += 10;
        System.out.println(brand + " speed: " + speed);
    }
}

// Object = Instance
Car myCar = new Car();   // Object created on Heap
myCar.brand = "Tesla";
myCar.accelerate();       // Tesla speed: 10

Internal Working — Memory Layout

02Four Pillars of OOP — Encapsulation, Inheritance, Polymorphism, AbstractionFAQImportant▼

1. Encapsulation

Wrapping data (variables) and code (methods) together as a single unit. Achieved via private fields + public getters/setters.

Java
public class BankAccount {
    private double balance;  // hidden from outside

    public double getBalance() { return balance; }
    public void deposit(double amount) {
        if (amount > 0) balance += amount;  // validation
    }
}

2. Inheritance

A class (child) acquires properties and behaviors of another class (parent). Uses extends keyword. Promotes code reusability.

Java
class Animal {
    void eat() { System.out.println("Eating..."); }
}
class Dog extends Animal {
    void bark() { System.out.println("Barking!"); }
}
// Dog inherits eat() from Animal
Dog d = new Dog();
d.eat();   // Eating...
d.bark();  // Barking!

3. Polymorphism

One interface, multiple implementations. Two types: Compile-time (overloading) and Runtime (overriding).

Java
// Runtime Polymorphism
Animal a = new Dog();    // Upcasting
a.sound();               // Calls Dog's sound() — decided at RUNTIME

4. Abstraction

Hiding implementation details and showing only functionality. Achieved via abstract classes and interfaces.

Java
abstract class Shape {
    abstract double area();  // no body — subclass must implement
}
class Circle extends Shape {
    double radius;
    double area() { return Math.PI * radius * radius; }
}
03Constructors — Default, Parameterized, Copy, ChainingFAQ▼

What is a Constructor?

A special method called automatically when an object is created. It has the same name as the class and no return type.

Java
public class Student {
    String name;
    int age;

    // Default constructor
    Student() {
        this("Unknown", 0);  // Constructor chaining
    }

    // Parameterized constructor
    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // Copy constructor
    Student(Student other) {
        this.name = other.name;
        this.age = other.age;
    }
}
📌 Key Points

• Compiler adds a default no-arg constructor only if you don't define any.
• this() must be the first statement in a constructor.
• Constructors are NOT inherited.

// Abstract class — HAS shared code
abstract class Vehicle {
    int speed;
    void stop() { speed = 0; }  // concrete method
    abstract void start();       // must be implemented
}

// Interface — defines CONTRACT
interface Flyable {
    void fly();
    default void land() { System.out.println("Landing..."); }
}

// A class can extend ONE class + implement MANY interfaces
class Helicopter extends Vehicle implements Flyable {
    void start() { System.out.println("Rotor starting..."); }
    public void fly() { System.out.println("Flying!"); }
}
06SOLID PrinciplesImportant▼
  • S — Single Responsibility: A class should have only one reason to change.
  • O — Open/Closed: Open for extension, closed for modification.
  • L — Liskov Substitution: Subtypes must be substitutable for their base types.
  • I — Interface Segregation: Many specific interfaces > one general-purpose interface.
  • D — Dependency Inversion: Depend on abstractions, not concretions.
Java
// ❌ Violates SRP — class does too much
class UserService {
    void createUser() { }
    void sendEmail() { }      // separate concern!
    void generateReport() { } // separate concern!
}

// ✅ Follows SRP — each class, one job
class UserService   { void createUser() { } }
class EmailService  { void sendEmail() { } }
class ReportService { void generateReport() { } }

// ✅ Dependency Inversion
interface NotificationService { void send(String msg); }
class EmailNotification implements NotificationService {
    public void send(String msg) { /* email logic */ }
}
class OrderService {
    private NotificationService notifier; // depends on abstraction
    OrderService(NotificationService ns) { this.notifier = ns; }
}
