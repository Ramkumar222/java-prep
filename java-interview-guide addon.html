01 Java Basics ▶
History & Features of Java

Java was created by James Gosling at Sun Microsystems in 1995. Originally named "Oak", it was designed for embedded systems before becoming the dominant enterprise language.

WORAOOPPlatform IndependentRobustSecure
  • Write Once, Run Anywhere (WORA) — Java compiles to bytecode that runs on any JVM
  • Object-Oriented — Everything revolves around classes and objects
  • Platform Independent — JVM abstracts OS differences
  • Strongly Typed — Every variable must have a declared type
  • Automatic Memory Management — Garbage Collector handles deallocation
  • Multi-threaded — Built-in support for concurrent programming

Wrapper Classes

OOP Basics
public class Person {
    // Fields (instance variables)
    private String name;
    private int age;
    static int count = 0;  // shared across all instances

    // Default constructor
    public Person() {
        this("Unknown", 0);  // constructor chaining
    }

    // Parameterized constructor
    public Person(String name, int age) {
        this.name = name;  // 'this' disambiguates field vs param
        this.age = age;
        count++;
    }

    // Copy constructor
    public Person(Person other) {
        this(other.name, other.age);
    }

    // Getters & Setters (Encapsulation)
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    @Override
    public String toString() {
        return "Person{" + name + ", " + age + "}";
    }
}

// Usage
Person p1 = new Person("Alice", 30);
Person p2 = new Person(p1);     // copy
System.out.println(Person.count); // 2

Inheritance Example
class Animal {

    void sleep() { System.out.println(name + " sleeps"); }

}

Abstract Class & Interface
// Abstract class — partial implementation
abstract class Shape {
    String color;
    Shape(String color) { this.color = color; }

    abstract double area();    // subclass MUST implement
    void display() {           // concrete method
        System.out.println("Color: " + color + ", Area: " + area());
    }
}

class Circle extends Shape {
    double radius;
    Circle(String color, double r) { super(color); this.radius = r; }
    @Override
    double area() { return Math.PI * radius * radius; }
}

// Interface — capability contract
interface Drawable {
    void draw();                          // abstract
    default void print() {               // Java 8: default method
        System.out.println("Printing...");
    }
    static void info() {                 // Java 8: static method
        System.out.println("Drawable interface");
    }
    private void helper() { }            // Java 9: private method
}

interface Resizable {
    void resize(double factor);
}

// Class implements multiple interfaces!
class Square extends Shape implements Drawable, Resizable {
    double side;
    Square(double s) { super("blue"); this.side = s; }
    @Override double area() { return side * side; }
    @Override public void draw() { System.out.println("Drawing square"); }
    @Override public void resize(double f) { side *= f; }
}

Fail-Fast vs Fail-Safe Iterators
Iterator Types
// Fail-fast: throws ConcurrentModificationException if modified during iteration
// Used by: ArrayList, HashMap, HashSet
List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c"));
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    if (s.equals("b")) it.remove();  // ✅ safe removal via iterator
    // list.remove(s);  ← ❌ ConcurrentModificationException!
}

// Fail-safe: works on a copy, no exception
// Used by: CopyOnWriteArrayList, ConcurrentHashMap
CopyOnWriteArrayList<String> cowList = new CopyOnWriteArrayList<>();
cowList.add("a"); cowList.add("b");
for (String s : cowList) {
    cowList.add("c");  // ✅ safe but iterates old snapshot
}

  HashMap Internal Structure (Java 8+):
  - Backed by array of "buckets" (Node[])
  - Default initial capacity: 16
  - Load factor: 0.75 (resize when 75% full)
  - Each bucket: LinkedList (or Red-Black Tree if chain length ≥ 8)

  put(key, value) process:
  1. hashCode(key) → hash → index = hash & (capacity-1)
  2. If bucket empty → insert new Node
  3. If collision:
     a. key.equals() existing key? → update value
     b. Else → append to chain (LinkedList/TreeNode)
  4. If size > capacity * loadFactor → resize (double capacity)

  Why capacity is power of 2?
  → index = hash % capacity = hash & (capacity-1)  [faster bitwise op]

Rate Limiter Design
Token Bucket Rate Limiter
public class RateLimiter {
    private final int maxTokens;
    private final int refillRate;       // tokens per second
    private int currentTokens;
    private long lastRefillTime;

    public RateLimiter(int maxTokens, int refillRate) {
        this.maxTokens = maxTokens;
        this.refillRate = refillRate;
        this.currentTokens = maxTokens;
        this.lastRefillTime = System.currentTimeMillis();
    }

    public synchronized boolean tryAcquire() {
        refill();
        if (currentTokens > 0) {
            currentTokens--;
            return true;   // allowed
        }
        return false;      // rate limited
    }

    private void refill() {
        long now = System.currentTimeMillis();
        long elapsed = (now - lastRefillTime) / 1000;
        if (elapsed > 0) {
            currentTokens = Math.min(maxTokens, currentTokens + (int) (elapsed * refillRate));
            lastRefillTime = now;
        }
    }
}

What is JWT?

JSON Web Token (JWT) is an open standard (RFC 7519) for securely transmitting information between parties as a compact, URL-safe JSON object. It is digitally signed — so the server can verify it without storing session state (stateless auth).

A JWT has 3 parts separated by dots: header.payload.signature

JWT Structure Breakdown

.eyJzdWIiOiJ1c2VyQGVtYWlsLmNvbSIsInJvbGUiOiJVU0VSIiwiZXhwIjoxNzAwMDAwMDAwfQ==

{ "alg": "HS256", "typ": "JWT" }

JwtUtil — Generate & Validate Tokens
@Component
public class JwtUtil {

    @Value("${jwt.secret}")
    private String secretKey;   // store in application.properties / env var

    private static final long EXPIRY_MS = 86400000; // 24 hours

    // ── Generate Token ──
    public String generateToken(String username, String role) {
        return Jwts.builder()
            .setSubject(username)
            .claim("role", role)
            .setIssuedAt(new Date())
            .setExpiration(new Date(System.currentTimeMillis() + EXPIRY_MS))
            .signWith(getSignKey(), SignatureAlgorithm.HS256)
            .compact();
    }

    // ── Extract Claims ──
    public Claims extractAllClaims(String token) {
        return Jwts.parserBuilder()
            .setSigningKey(getSignKey())
            .build()
            .parseClaimsJws(token)
            .getBody();  // throws if token is tampered/expired
    }

    public String extractUsername(String token) {
        return extractAllClaims(token).getSubject();
    }

    public boolean isTokenExpired(String token) {
        return extractAllClaims(token).getExpiration().before(new Date());
    }

    public boolean validateToken(String token, UserDetails userDetails) {
        final String username = extractUsername(token);
        return username.equals(userDetails.getUsername()) && !isTokenExpired(token);
    }

    private Key getSignKey() {
        byte[] keyBytes = Decoders.BASE64.decode(secretKey);
        return Keys.hmacShaKeyFor(keyBytes);
    }
}
JWT Filter — Intercepting Every Request
JwtAuthFilter — Validates Token on Each Request
@Component
public class JwtAuthFilter extends OncePerRequestFilter {

    @Autowired private JwtUtil jwtUtil;
    @Autowired private UserDetailsService userDetailsService;

    @Override
    protected void doFilterInternal(HttpServletRequest req,
                                      HttpServletResponse res,
                                      FilterChain chain) throws Exception {

        String authHeader = req.getHeader("Authorization");

        // 1. Check if Bearer token is present
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            chain.doFilter(req, res);  // no token — let it pass (public endpoints)
            return;
        }

        String jwt = authHeader.substring(7);  // strip "Bearer "
        String username = jwtUtil.extractUsername(jwt);

        // 2. Load user and validate token
        if (username != null && SecurityContextHolder.getContext().getAuthentication() == null) {
            UserDetails userDetails = userDetailsService.loadUserByUsername(username);

            if (jwtUtil.validateToken(jwt, userDetails)) {
                // 3. Set authentication in SecurityContext
                UsernamePasswordAuthenticationToken authToken =
                    new UsernamePasswordAuthenticationToken(
                        userDetails, null, userDetails.getAuthorities());
                authToken.setDetails(new WebAuthenticationDetailsSource().buildDetails(req));
                SecurityContextHolder.getContext().setAuthentication(authToken);
            }
        }
        chain.doFilter(req, res);   // continue down the filter chain
    }
}

    public synchronized void increment() {

Producer-Consumer with wait/notify
class SharedQueue {
    private final Queue<Integer> queue = new LinkedList<>();
    private final int CAPACITY = 5;

    public synchronized void produce(int item) throws InterruptedException {
        while (queue.size() == CAPACITY) {
            wait();  // releases lock, waits until notified
        }
        queue.add(item);
        System.out.println("Produced: " + item);
        notifyAll();  // wake up waiting consumers
    }

    public synchronized int consume() throws InterruptedException {
        while (queue.isEmpty()) {
            wait();  // wait until producer adds an item
        }
        int item = queue.poll();
        System.out.println("Consumed: " + item);
        notifyAll();  // wake up waiting producers
        return item;
    }
}

bq.take();   // blocks if empty — no manual wait/notify needed!

    System.out.println(f.get());   // Task C, A, B — order same as submission
}

// invokeAny() — returns result of the FIRST task to complete
String fastest = pool.invokeAny(tasks);   // "Task C done" (50ms wins)
pool.shutdown();

);

    () -> System.out.println("Poll DB"),
    1, 3, TimeUnit.SECONDS    // wait 3s AFTER each run finishes
);

Logging Hierarchy in Spring Boot

Spring Boot uses SLF4J as the logging facade and Logback as the default implementation. You write code against SLF4J — so you can swap Logback for Log4j2 without changing any application code.

LevelPriorityWhen to Use
TRACELowestVery fine-grained debug (loop iterations, variable values)
DEBUGLowDetailed flow info (method entry/exit, query params)
INFOMediumNormal lifecycle events (app started, request received)
WARNHighPotential issues (deprecated API, retrying, slow query)
ERRORHighestFailures that need attention (exceptions, DB down)
Rule: If a logger is set to INFO, it will log INFO + WARN + ERROR but suppress DEBUG and TRACE.

MDC — Adding Request Context to Every Log Line
MDC (Mapped Diagnostic Context) — Trace ID in Logs
// MDC lets you attach key-value data that appears in every log line
// within that thread — great for correlating logs by requestId/userId

@Component
public class LoggingFilter implements Filter {

    @Override
    public void doFilter(ServletRequest req, ServletResponse res, FilterChain chain)
            throws IOException, ServletException {
        try {
            String requestId = UUID.randomUUID().toString().substring(0, 8);
            MDC.put("requestId", requestId);   // attach to thread-local
            MDC.put("userId", getCurrentUserId());
            chain.doFilter(req, res);
        } finally {
            MDC.clear();  // MUST clear to avoid leaking into next request
        }
    }
}

// In logback pattern, reference with %X{requestId}:
// pattern: "%d [%X{requestId}] [%X{userId}] %-5level %logger - %msg%n"
// Output:   2024-01-15 [a3f2bc91] [user@mail.com] INFO  OrderService - Order placed

// Now every log line in that request automatically shows the requestId!
// Invaluable when debugging logs from multiple concurrent requests.
